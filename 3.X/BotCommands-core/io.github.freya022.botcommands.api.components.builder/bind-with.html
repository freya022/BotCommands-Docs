Binds the given handler to this component.

Handler data

The data passed is serialized and later deserialized using their resolver.

Each passed object needs to correspond to a parameter of the function (in the declaration order, excluding non-data parameters).

For objects supported by ComponentParameterResolvers, you must annotate your parameter with @ComponentData.

For serializable objects, you must instead use @SerializableComponentData.

Remember the parameters need to be annotated with @ComponentData.
